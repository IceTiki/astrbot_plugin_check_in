# AstrBot 习惯打卡 v1.9.0

基于 v1.8.0，统一 QQ 用户端命令体系，并内置完整 Metro 图片帮助。**数据库保持 SQLite，无需重置账户或历史打卡数据。**

## v1.9.0 改动

- 日常仅支持 `/打卡 习惯名称`，每次只增加 **1 次**。移除编号打卡、`+2` 等批量打卡、普通打卡附带历史日期及批量补签。
- 任务新增／修改／恢复统一为 `/打卡 任务 目标 名称 次数`。任务删除是软删除，历史记录保留。
- 查询、补签、清除统一放到 `/打卡 记录 ...`；计分与时间设置统一为 `/打卡 任务 ...`。
- 月历、社交、账户、群提醒按「月历」「好友」「账户」「群设置」分组。
- 个人默认显示在 `/打卡 视图` 下设置：今日／月历／帮助图片或文字、快捷操作类型。
- `/打卡 帮助` 默认发送**完整 41 条命令示例的 Metro 图片帮助**，和纯文字版共用单份 `help_content.py` 数据。缺少 Pillow/中文字体或图片发送失败时拆分发送完整文字帮助。
- 个人默认视图按账号统一：相同账号在群聊和私聊共用偏好，不影响其他账号；迁移旧的会话级显示偏好时保留旧行，不清空原值。
- QQ 按钮与文字链接均发送新命令，移除 `+1` 形式；定时提醒文字也使用新命令。
- 删除旧命令解析入口，而非永久保留历史别名；曾创建的同名任务和历史记录依然留在数据库。
- **计分方式仍为 v1.7 的连续半衰期，凌晨 04:00 换日；不改历史得分或历史记录。**

## 行为说明

1. `/打卡` 查看今日状态。`/打卡 工作一小时` 一次记录 1 次（默认目标每天 3 次）。
2. `/打卡 任务 目标 运动 3`：
   - 首次创建：每天 3 次，权重默认 1。
   - 当前已启用：更新每天目标次数。
   - 历史中存在但已停用：恢复并更新目标次数，历史打卡记录保留。
3. `/打卡 任务 删除 运动` 停用习惯，不删除原有 SQLite 记录。
4. `/打卡 任务 时间 睡觉 23:30 30`：最佳 23:30，半衰期 30 分钟；`时间 运动 关闭` 关闭限时计分。更新规则从今天的打卡日生效，旧日期仍保留历史规则。
5. `/打卡 记录 补签 ...` 每次只有 1 次，日期最多向前 14 天（可改配置）。限时任务必须给出真实完成时间。
6. `/打卡 记录 清除 睡觉` 清除这一天该任务的**全部记录**，不是减少一次。
7. 新用户不能创建与系统命令冲突的任务名；纯数字任务名也不允许，以免与旧编号模式混淆。
8. 从旧 v1.8 升级后，旧命令（例如 `/打卡 添加`、`/打卡 月历视图`、`/打卡 交互`）不再受理，统一提示参考新帮助。
9. QQ 官方机器人图片和快捷按钮有可能分别发送两条消息。QQ 客户端是否成功展示取决于其接口和权限，不保证一定支持图片和快捷按钮。
10. 最长帮助图片约 1080×4501；QQ 压缩后可双击放大。要纯文字请执行 `/打卡 视图 帮助 文字`。

## 个人默认视图与数据库迁移

数据库文件仍是 `data/plugin_data/astrbot_plugin_daka/checkin.sqlite3`。

首次运行 v1.9 时会对旧数据库创建一次 `data/backups/astrbot_plugin_daka/pre-1.9-*.sqlite3` 快照（如果 `PRAGMA user_version < 10900`）。保留所有旧表，并仅对 `ui_preferences` 表追加可空列 `help_view_mode`，不创建独立数据库。

使用个人账户的 `scope` + 固定 `origin=__person__` 存储新偏好，原来的 `scope` + 群聊/私聊 `origin` 行保留供回滚。如果群聊与私聊保存了不同的偏好，**首次使用 v1.9 的会话**会决定迁移的初始值，之后同步。

在个人账户合并之前已分别保存的偏好可能随账户合并采用目标账户的默认值；**数据本身不会被清空**。如果需更改，只需重新发送 `/打卡 视图` 设置。

## 部署说明：Debian + Docker

既有服务器目录 `/opt/services/astrbot`、容器 `astrbot`。

**不要先在 AstrBot WebUI 卸载旧插件**。WebUI 卸载可能连 `plugin_data` 一并删除。

推荐先运行配套更新脚本 `--check-only` 检查安装目录与 Docker bind mount，确认后停止容器、备份源码及 `plugin_data`、只更换插件代码并启动容器：

```bash
cd /opt/services/astrbot
python3 update_astrbot_daka_v1.9.0.py astrbot_plugin_daka_v1.9.0.zip --check-only
python3 update_astrbot_daka_v1.9.0.py astrbot_plugin_daka_v1.9.0.zip
docker logs --since 3m --tail=150 astrbot
```

可在 AstrBot 插件设置中配置 `help_display_mode=image/text`，用户也可通过 `/打卡 视图 帮助 图片|文字` 分别保存个人偏好。

**中文图片字体**：建议 Docker 环境安装 Noto Sans CJK（例如 Debian 的 `fonts-noto-cjk`），否则帮助自动回退完整文字版。Pillow>=10 必需。
